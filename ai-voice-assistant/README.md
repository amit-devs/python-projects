# 🎤 Mini Voice Assistant (Python)

A simple Python project that listens to your voice and responds using speech.

## Features

* Voice input using microphone
* Speech-to-text conversion
* Text-to-speech responses
* Tell date and time
* Open websites (Google, YouTube)
* No audio files saved (runs in memory)
* Clean exit with microphone release

## Installation

Install required libraries:

pip install sounddevice SpeechRecognition pyttsx3 numpy

## Run

python main.py

## Usage

* Press **Enter** to start speaking
* Speak your command
* Type **q + Enter** to exit

## Requirements

* Working microphone
* Internet connection (for speech recognition)

## Output

* Displays recognized text in terminal
* Responds using voice output
